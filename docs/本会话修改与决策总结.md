# BeLoong Core 本会话修改与决策总结

## 一、会话目标

本会话围绕：

1. 龙宫 `beloong:loong_palace` 自定义维度天空；
2. Dramatic Skys 资源包天空效果迁移；
3. 自定义维度天气/云/雾视觉处理；
4. 参考 NeoForgeSkyboxes（Nuit）源码；
5. Sodium / Iris 可选依赖接入。

---

## 二、最终决策清单

| 决策点 | 最终选择 |
|---|---|
| 龙宫 `has_skylight` | 保持 `true`，保留真实天空光照 |
| 龙宫天气 | 服务端保留原版天气；客户端视觉隐藏 |
| 龙宫云 | 客户端禁用：`renderClouds()` 返回 `true` |
| 龙宫雨雪/雨声 | 客户端禁用：`renderSnowAndRain()` 返回 `true`、`tickRain()` 返回 `true` |
| 龙宫雾 | NeoForge `ViewportEvent.RenderFog` 禁用 |
| Dramatic Skys 天空渲染 | 单图集 3×2 Cube UV 渲染，不切六面贴图 |
| 天空过渡 | 逐 tick 平滑 alpha + 时间跳变长过渡 |
| 基础天空层 | 已添加后删除，最终不使用纯色基础底层 |
| 太阳/月亮 | 使用资源包 sun.png / moon_phases.png 绘制 |
| 图层旋转 | 完整开启 |
| Mixin 修改 Minecraft | 未新增任何原版 Mixin |
| 天灾维度 | 保持原版，未修改 |

## 四、主要实现过程与决策点

### 4.1 初期迁移

- 确定龙宫使用 `nebula` 天空盒；
- 天灾维度先尝试 `overworld_cubemap`，后因资源包不可用完全回退；
- 龙宫最终改为 Dramatic Skys。

### 4.2 OptiFine / Celestial 面映射

- 研究 OptiFine 文档 `skybox.png`；
- 确认 3×2 图集布局：

```text
┌──────────┬──────────┬──────────┐
│ Bottom   │ Top      │ South    │
├──────────┼──────────┼──────────┤
│ West     │ North    │ East     │
└──────────┴──────────┴──────────┘
```

- 采用 Celestial JSON 24 顶点 UV 表作为最终实现依据。

### 4.3 太阳/月亮黑色背景问题

- 现象：太阳/月亮显示为黑色方形；
- 原因：缺少原版加色混合；
- 修复：在 `SkyDecorationsRenderer` 中使用：

```java
RenderSystem.blendFuncSeparate(
    SRC_ALPHA, ONE,
    ONE, ZERO
);
```

### 4.4 过渡平滑问题（多次迭代）

1. **第一版**：固定 20 tick 平滑 alpha；
   - 失败：时间跳变后过渡太快。
2. **第二版**：加入 `lastDayTime` 检测，时间跳变使用 200 tick；
   - 失败：`timeJump` 只在第一帧为 true，后续又回到 20 tick。
3. **第三版**：引入 `unexpectedTransitionActive` 长过渡状态；
   - 时间跳变后持续使用 200 tick，直到 alpha 收敛；
   - 有效，但发现 SCREEN 混合不随 alpha 变淡。
4. **第四版（真正修复）**：
   - `SkyBlendMode` 改为 `apply(float alpha)`；
   - SCREEN 使用：
     ```java
     RenderSystem.setShaderColor(alpha, alpha, alpha, 1.0F);
     ```
   - 至此过渡效果正常。

### 4.5 基础天空层

- 参考 `OverworldSkybox` 发现缺少 `sky0_overworld` 底层；
- 临时添加纯色立方体基础层；
- 后来确认：
  - 该层不是过渡修复的关键；
  - 纯色底层导致画面与参考模组差异明显；
- **最终删除**。

### 4.6 天气/云/雾

- 早期尝试过 `has_skylight: false` 数据包禁用天气；
- 后改为保留 `has_skylight: true` 且服务端不抑制天气；
- 最终采用客户端视觉禁用：
  - 隐藏云；
  - 隐藏雨雪渲染；
  - 隐藏雨声/雨粒子；
  - 使用 `ViewportEvent.RenderFog` 禁雾。

- 无新增原版 Mixin；

### 待处理 / 注意
1. **Sodium / Iris 可选依赖已加入，但曾出现启动崩溃**
   - 原因高度疑似 CurseForge Sodium 是 JarJar 外层包，Iris 找不到 Sodium 内部类；
   - 尚未最终修复/回退。
2. **调试日志仍在**
   - `DramaticSkyRenderer` 和 `LoongPalaceSkyTickHandler` 保留了 `[SkyDebug]` 日志；
   - 验证完成后可以删除/降低频率。
3. **纯色基础层已删除**
   - 需再次确认画面与参考模组一致。
4. **过渡时长可调**
   - `UNEXPECTED_TRANSITION_TICKS = 200`，约 10 秒；
   - 如需要可调大/调小。
5. **太阳/月亮位置与旋转可能仍需微调**
   - 目前使用 vanilla 式旋转；
   - 后续如需更接近 Celestial/Nuit 可再调整。
