# 月亮贴图优化 · 目视 A/B 验收记录

**目的**：验证 `2da1206`（月亮优化）有没有改变月亮的**朝向、大小、位置、边缘质量**。
**方法**：同一机位、同一朝向、同一时刻（午夜）、只改相位，逐相位截图后做像素级量化对比。
**截图归档**：`docs/pictures/moon-phase-ab/after/`（改后 `2da1206`）、`docs/pictures/moon-phase-ab/before/`（改前 `cb2b1ee`）、`diff-x4.png`（放大 4 倍的差分）
**结论**：**通过** —— 见第六节。

```
/execute in beloong:loong_palace run tp @s 0 64 0 0 -90
```

### 1.1 尺寸：与设计值吻合到 0.5 px

贴图实测满月亮盘 bbox = 243 px（320 px 画布），画布对应 **22.4** 世界单位
⇒ 盘面直径 = `243 × 22.4 / 320` = **17.01 世界单位**。

距离 100、FOV 70、画面高 1009 px，用正切投影：

```
盘面半角 = atan(17.01 / 2 / 100) = 4.8624°
屏幕直径 = 1009 × tan(4.8624°) / tan(35°) = 1009 × 0.085051 / 0.700208 = 122.6 px
```

**实测 122 px**（亮斑 bbox 122×122）⇒ 误差 **0.6 px**，裁剪框与 quad 补偿的换算正确。

### 1.2 月牙不横跳（本次优化最大的风险点）—— **通过**

相位 1/2/3 的亮面**全部落在屏幕右侧**，质心 dx/R 稳定在 +0.49 → +0.70，**没有左右翻转**。
这正是「8 张共用同一居中裁剪框」要保证的东西（相位 4 只有暗盘，裁剪框一旦按亮部 bbox 自适应，
月牙就会随相位横跳）。

### 1.3 亮面左右是**镜像**的 —— 但**不是本次优化引入的**

贴图里相位 1/2/3 的亮面在 **u≈0 侧（贴图左缘）**，屏幕上却出现在**右侧**。属既有现象，理由见第二节。
归入 **M2**（本模组用 `R_z(θ)` 取代原版 `R_y(-90)·R_x(θ)`）的范畴，需靠 A/B 判定是否与改前一致。

### 1.4 暗盘（earthshine）与边缘

- 暗盘外沿 ≈ **r 73–75 px**。贴图里内容延伸到 158 px 而亮盘半径 121.5 px，比值 **1.30**；

- 满月边缘径向剖面（1 px 步进，整圈均值）：

  盘边过渡约 **2 px**（含一级中间值 135），暗盘向外平滑衰减到天空本底（≈27）**无块状**。

### 1.5 竖直无渲染接缝

## 二、等价性论证：A/B **应当**完全一致

改前（图集）与改后（8 张独立贴图）在几何与 UV 上逐项等价，因此在同一机位下**朝向、大小、位置都不应变**：

| | 改前（图集，格子区间） | 改后（单格，0..1） |
|---|---|---|
| 顶点顺序 | `(−20,−100,+20) → (+20,−100,+20) → (+20,−100,−20) → (−20,−100,−20)` | 同序，`±20 → ±11.2` |
| UV | `(endX,endY) (startX,endY) (startX,startY) (endX,startY)` | `(1,1) (0,1) (0,0) (1,0)` |

`endX = (j+1)/4` 换算到单格内即 `1`，`startX = j/4` 即 `0` ⇒ **同一角点拿到同一 UV**。
裁剪比 `560/1000 = 0.56`，quad 同步 `40 → 22.4`，故「每世界单位对应的贴图内容」不变：

```
改前：盘面 425 texel ÷ 40 单位 = 10.63 texel/单位
改后：盘面 243 texel ÷ 22.4 单位 = 10.85 texel/单位   （残差来自两次重采样，<2%）
改前：盘面 425 texel ÷ 25 texel/单位 = 17.00 世界单位
改后：盘面 243 texel ÷ 14.286 texel/单位 = 17.01 世界单位
```

网格顶点顺序与 UV 完全一致，UV 只是从「图集坐标」平移到「单图坐标」⇒ **渲染结果应逐位相同**
（唯一差别是纹理过滤与重采样，不改变朝向与尺度）。

**可证伪的预测**：改前截图应与上表**同号、同侧、同尺寸**；亮盘直径仍为 **≈122 px**；
亮面仍出现在**屏幕右侧**。若改前出现左侧亮面或尺寸变化，则上述等价性论证被推翻。

### 6.1 两点必须记录的方法学问题

1. **准星会污染统计。** 过盘心扫描线显示 x ∈ [−15, +12] 区间亮度 192–219，那是**画面正中准星**，
   不是月亮。它让「亮占比」「左半均」被抬高约几个百分点。因为 A/B 都带准星，**对比结论不受影响**，
   但绝对数值不可当作月相亮面比例使用。
2. **缩略图肉眼判断不可靠。** 我最初从预览图误判相位 1 的亮面在左侧，与数值矛盾；
   打印 ASCII 亮度图 + 过盘心扫描线后定论为**右侧**。扫描线直接给出：左缘至 x≈−20 亮度 ≈31（天空本底），
   x=+20…+60 由 113 递增到 232。**最终结论以像素数据为准。**

### 6.2 顺带确认：屏幕上的亮面相对贴图是**镜像**的

贴图里相位 1/2/3 的亮面在 **u≈0 侧**，屏幕上出现在**右侧**。这是**既有行为**（A/B 一致），
归入审查报告里的 **M2**（本模组以 `R_z(θ)` 取代原版 `R_y(−90)·R_x(θ)`），
**不是**本次优化引入的。是否要「修正」取决于要不要去对齐原版朝向 —— 需先与原版月牙目视比对。
