### 0.3 最值得先看的五条

1. **【L1-1 / S2】`terrablender` 没锁版本，而代码硬依赖 4.1.0.8 的克隆语义** ——
   装 TB ≤ 4.1.0.7 时 `CloneParameterListMixin:79` 的 `receiver.clone()`（**在 try 之外**）
   会 NPE 并穿透无 try/catch 的 `initializeOnServerStart` 循环 ⇒ **服务端启动失败**。
   可达性已证：BWG 2.6.0 自己只要求 `[4.1.0.0,)`。**修法一行。**

2. **【L6-S2-2 / S2，已实跑复现】照文档重跑贴图脚本会静默改写 2/10 张已提交贴图** ——
   产出冰 **12×15**、风 **13×15**，而仓库提交的是 **12×14 / 13×14**；
   `memory/learned-patterns.md:372` 记的那次事故**数字完全一致，从未被消除**，
   且备份落在被 gitignore 的 `preview/` 下。

3. **【L4-S2-1 / S2】技能 `cooldown: 5.0` 的单位是 tick 不是秒** ——
   DS 的 `activation.cooldown` 无秒→tick 换算（锁定 jar `javap -c` 实证），
   所以 `5.0` = **5 tick**，而 NBT 冷却是 **60 tick** ⇒ **差 20 倍且方向与文档相反**；
   传送后第 5–60 tick 每次按键只弹 actionbar，**正是该改动想消除的现象**。

4. **【L4-S2-2 / S2】龙宫传送丢失 `POST_TELEPORT` 落点票据** ——
   改用 `changeDimension` 后票据不再申领，而**两条调用方都不补**。
   这**推翻**了 `dimension-transport-nonblocking-design.md:36-38` 与 `memory/learned-patterns.md`
   论证"不需要等待机制"的**唯一依据**。

5. **【L3-S3-1 / 建议按 S2 优先修】waterlogged 方块被判为"空"** ——
   在完整荧石框内放**一个 waterlogged 台阶**就点亮门，并把框内方块**无掉落静默替换**。
   **本轮唯一"玩家可自然触发且造成物品损失"的项。**

### 2.1 证据规则（硬约束）

   或改用 `javap -p` 打**实际 jar**；等级 C 不得作为定级依据。

4. **可复现**：每条发现附产生结论的命令或读取路径。
5. **只读**：审查期间 `src/` 零修改（`git status` 已确认）。
