# 【化龙】整合包任务设计思路

## 序章 龙宫

### 概述
龙宫是一个独立的维度，使用固定的地图存档，作为整合包的主城。功能有新手引导、剧情系统、商店、龙之赛环小游戏等。
龙宫设定上，悬浮在九天之上，统御着龙星上的所有龙族，发号施令，地位至高无上。在数百年前，龙族与人类方展开合作。每年，龙宫都会从地面挑选出具备龙之血脉的孩子，进入龙宫，进行血脉觉醒。觉醒龙之血脉的人，可以通过化龙池或者龙之祭坛，变成龙族，称之为“化龙者”。每位化龙者的血脉不同，化为的龙的种族也不同。
龙族分为主龙和从龙两个阶级。其中主龙固定只有九条，从龙的数量不定。
九条主龙分别是洞穴龙、森林龙、海洋龙、苔原龙、星辰龙、晶咒龙、以太龙、地黄龙、亢金龙。

### 任务大概流程
当玩家第一次进入世界存档时，会出生在龙宫维度的中央大平台。平台上有一个NPC “末”，末负责将玩家带领到龙宫的前殿。末会先介绍龙宫是什么地方，然后指引玩家进入龙宫前殿。玩家顺着指引进入龙宫前殿之后，会看到9条龙的雕像。在末的介绍下，玩家会了解到主龙与从龙的划分，以及每一种主龙的特性。了解完九种主龙后，在末的引领下，玩家来到化龙池。跳入化龙池水后，在选择界面选择要变化的龙。化龙完成后，末会先教玩家使用飞行。玩家需要使用飞行，飞到前殿的二楼。飞到二楼后，玩家会变得饿，此时末会介绍龙的饮食机制。

### FTB任务设计
进入龙宫维度-进入龙宫前殿-【主龙】与九种龙的雕像交互-【化龙池】前往化龙池-【化龙】在化龙池水中选择要变化的龙-【蹒跚学飞】学会使用飞行飞到龙宫二楼-【吃什么？】了解龙的饮食机制并且吃一个东西-【力量测试】学会使用龙的技能击杀僵尸-【技能加点】学会使用经验值加点技能-【技能禁用】使用ctrl左键点击技能实现禁用-【成长之路】学会吸收成长道具里的能量成长到下一阶段-【诅咒】了解诅咒和对抗方式-【圣龙】应龙消失，诅咒出现，龙族衰落，人族崛起，千年大战，龙族战败，退居山林，听闻寓言，中兴之主，人类之躯，身负龙血，重振龙族，寻得应龙。从而引出主线：寻找应龙，找到诅咒的根源。

### 具体任务
- 任务-【主龙】：新增一种方块，名为龙之雕像。右键雕像，可以弹出GUI，GUI界面信息包含龙的banner图片，龙的物种介绍，龙的成长阶段，龙的特性，龙的诅咒，龙的食谱。
- 任务-【化龙】：介绍化龙池和龙之祭坛可以随时切换龙种，但是会丢失成长进度。使用龙魂可以完整保存成长和技能。
- 任务-【吃什么】：使用额外乐事的进度“一点点”来判断。
