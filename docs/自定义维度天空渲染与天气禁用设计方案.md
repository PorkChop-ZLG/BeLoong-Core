# 龙宫自定义天空渲染与天气禁用设计方案

## 一、目标

为 BeLoong Core 的龙宫维度添加自定义天空渲染，并禁用龙宫天气。

| 维度 | 天气 | 自定义天空 |
|---|---|---|
| 龙宫 `beloong:loong_palace` | 禁用 | 使用 `nebula` 天空盒 |
| 天灾 `beloong:disaster` | 保留原版 | 完全保持原版，不做任何修改 |

> 天灾维度此前测试使用的 `nighttime sky by koto (1.0).zip` 资源包不可用，因此已完全回退天灾维度相关修改，恢复为原版 overworld 天空与天气。

## 二、约束与方向

1. **龙宫天气禁用采用数据包方案**：通过 `has_skylight: false` 实现，不写服务端代码。
2. **不得 Mixin 修改原版类**：所有原版行为通过 NeoForge 官方扩展点实现。
3. **尽量数据包化**：天气开关、维度特效 ID 均在数据包中配置。
4. **自定义天空需要少量客户端 Java 代码**：Minecraft/NeoForge 没有纯数据包注册自定义天空渲染器的机制，通过 `RegisterDimensionSpecialEffectsEvent` 实现。
5. **参考模组**：Eternal Starlight（永恒星光）。其自定义维度天空走 NeoForge `DimensionSpecialEffects` 客户端注册路线，不需要 Mixin 原版类。

## 三、现状分析

### 3.1 当前维度类型配置

`src/main/resources/data/beloong/dimension_type/loong_palace.json`

- `has_skylight: false`
- `effects: "beloong:loong_palace"`

`src/main/resources/data/beloong/dimension_type/disaster.json`

- 保持原版：
  - `has_skylight: true`
  - `effects: "minecraft:overworld"`

### 3.2 相关 Minecraft/NeoForge 机制

- `DimensionType` 的 JSON 字段 `effects` 是一个 `ResourceLocation`，客户端用它查找 `DimensionSpecialEffects`。
- NeoForge 提供客户端 mod 总线事件 `RegisterDimensionSpecialEffectsEvent`，允许为任意 `effects` ID 注册自定义 `DimensionSpecialEffects`。
- `DimensionSpecialEffects` 实现 NeoForge 扩展接口 `IDimensionSpecialEffectsExtension`，可覆盖：
  - `renderSky`
  - `renderClouds`
  - `renderSnowAndRain`
  - `tickRain`
- 服务端天气循环在 `ServerLevel#advanceWeatherCycle()` 中，只有 `dimensionType().hasSkyLight()` 为 `true` 时才会推进。因此龙宫设置 `has_skylight: false` 后，服务端不会为该维度推进天气。

## 四、数据包设计

### 4.1 龙宫维度类型

`src/main/resources/data/beloong/dimension_type/loong_palace.json`

```jsonc
{
  "ultrawarm": false,
  "natural": true,
  "coordinate_scale": 1.0,
  "has_skylight": false,
  "has_ceiling": false,
  "ambient_light": 0.0,
  "monster_spawn_light_level": 0,
  "monster_spawn_block_light_limit": 0,

  "bed_works": true,
  "respawn_anchor_works": false,
  "has_raids": true,
  "logical_height": 384,
  "min_y": -64,
  "height": 384,
  "infiniburn": "#minecraft:infiniburn_overworld",
  "effects": "beloong:loong_palace"
}
```

要点：

- `has_skylight: false`：数据包层面禁用龙宫天气循环。
- `effects: "beloong:loong_palace"`：客户端按该 ID 注册龙宫自定义天空。

### 4.2 天灾维度类型

不做任何修改，保持原版：

```jsonc
{
  "has_skylight": true,
  "effects": "minecraft:overworld"
}
```

### 4.3 不修改的内容

- 不修改 `dimension/*.json`。
- 不添加服务端天气代码。
- 不 Mixin 任何原版类。
- 不修改天灾维度天空、天气或资源。

## 五、客户端天空渲染设计

### 5.1 注册龙宫维度特效

在 `BeLoongCoreClient` 中监听 `RegisterDimensionSpecialEffectsEvent`：

```java
@SubscribeEvent
public static void registerDimensionEffects(RegisterDimensionSpecialEffectsEvent event) {
    event.register(
        ResourceLocation.fromNamespaceAndPath(BeLoongCore.MODID, "loong_palace"),
        new LoongPalaceSkyEffects()
    );
}
```

### 5.2 龙宫天空特效

`LoongPalaceSkyEffects` 继承 `DimensionSpecialEffects.OverworldEffects`，只覆写 `renderSky()`：

```java
public class LoongPalaceSkyEffects extends DimensionSpecialEffects.OverworldEffects {

    @Override
    public boolean renderSky(ClientLevel level, int ticks, float partialTick,
                             Matrix4f modelViewMatrix, Camera camera,
                             Matrix4f projectionMatrix, boolean isFoggy,
                             Runnable setupFog) {
        CubeSkyRenderer.render(
            modelViewMatrix,
            projectionMatrix,
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/up.png"),
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/down.png"),
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/north.png"),
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/south.png"),
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/east.png"),
            ResourceLocation.fromNamespaceAndPath("beloong", "textures/environment/loong_palace_sky/west.png")
        );
        return true;
    }
}
```

### 5.3 设计说明

- 龙宫特效**不覆写** `renderClouds`、`renderSnowAndRain`、`tickRain`。
- 原版云层、雨雪、雨声不会成为问题：龙宫通过 `has_skylight: false` 已从服务端禁用天气。
- 天灾不注册任何自定义 `DimensionSpecialEffects`，使用原版 overworld 特效与天气。

## 六、天空盒渲染器

参考原版 `LevelRenderer#renderEndSky()` 的立方体绘制方式。

- 在相机周围绘制一个六面立方体。
- 六个面分别绑定 `up/down/north/south/east/west` 贴图。
- 使用 `RenderSystem.setShader(GameRenderer::getPositionTexShader)`。
- 绘制前开启混合并关闭深度写入，绘制后恢复状态。

## 八、验证清单

1. 龙宫维度：
   - 显示 `nebula` 自定义天空盒。
   - 无雨、雪、雷。
   - `/weather rain` 不影响龙宫。
2. 天灾维度：
   - 已恢复原版 overworld 天空。
   - 原版天气/云/雨雪/雷声保持正常。
3. 主世界：
   - 不受影响。
4. 专用服务器：
   - 不加载客户端维度特效类，不崩溃。
5. 无 Mixin：
   - 不存在 targeting 原版类的 Mixin。

## 九、风险与注意事项

- `has_skylight: false` 会同时影响龙宫的天空光照传播。若以后需要日光/月光照亮方块，需要用 `ambient_light`、方块光源或其他方式补偿。
- 龙宫维度当前生物群系 `loong_palace` 本身 `has_precipitation: false`，即使不设置 `has_skylight: false` 也不会下雨；设置后则从服务端天气循环层面彻底关闭。
- 自定义天空必须使用客户端 `RegisterDimensionSpecialEffectsEvent`，这是 NeoForge 的官方扩展点，不涉及 Mixin。
- 如果希望龙宫使用更亮的 `nebula_bright.png`，只需将 `docs/pictures/loong_palace_sky/` 重新从 `nebula_bright.png` 切分生成，不需要改代码。
