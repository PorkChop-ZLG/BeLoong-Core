# 龙宫 Dramatic Skys 天空渲染设计方案

## 一、目标

将 Dramatic Skys 资源包的昼夜天空效果迁移到龙宫维度，并保留龙宫原版天气系统。

| 维度 | 天空 | 天气 |
|---|---|---|
| 龙宫 `beloong:loong_palace` | Dramatic Skys 昼夜天空 | 保留原版天气 |
| 天灾 `beloong:disaster` | 原版 overworld 天空 | 保留原版天气 |

## 二、关键决策

- `has_skylight`：保持 `true`，保留完整天空光照。
- 天气：**不再禁用原版天气**。
- 不添加任何天气抑制代码。
- 第一阶段只实现昼夜天空：`stars` / `mask` / `day` / `night` 四层。
- 暂不实现太阳、月亮、阳光 flare 和层旋转。
- 天灾维度不做任何修改。

## 四、客户端渲染

### 4.1 单图集 Cube UV 渲染

新增 `CubeAtlasSkyRenderer`：

- 直接使用 `3072×2048` 的 3×2 六面图集。
- 采用 Dramatic Skys / Celestial JSON 提供的 24 顶点 UV 表绘制六面。
- 不再把图集切成六张独立贴图。

### 4.2 混合模式

新增 `SkyBlendMode`：

| 模式 | 实现 |
|---|---|
| `ALPHA` | `SRC_ALPHA, ONE_MINUS_SRC_ALPHA` |
| `ADD` | `SRC_ALPHA, ONE` |
| `SCREEN` | `ONE, ONE_MINUS_SRC_COLOR` |

### 4.3 四层昼夜渲染

新增 `DramaticSkyRenderer`，渲染顺序：

1. `stars.png`：alpha，透明度 = `nightFade`
2. `mask.png`：alpha，透明度 = `nightFade`
3. `day.png`：screen，透明度 = `dayFade`
4. `night.png`：add，透明度 = `nightFade`

透明度函数由 `dayTime` 计算，参考 Celestial `variables.json` 的昼夜 fade 公式。

### 4.4 龙宫特效

`LoongPalaceSkyEffects`：

- 继承 `DimensionSpecialEffects.OverworldEffects`
- 只覆写 `renderSky()`
- 调用 `DramaticSkyRenderer.render(...)`
- 不干预云、雨雪、雨声

## 五、资源文件

复制自 Dramatic Skys：

```
src/main/resources/assets/beloong/textures/skybox/
├── day.png
├── night.png
├── stars.png
└── mask.png
```

不再使用旧 `loong_palace_sky/` 六面贴图。

## 六、验证清单

1. 龙宫：
   - 白天显示 Dramatic Skys 白天天空。
   - 夜晚显示 night + stars + mask。
   - 昼夜 fade 过渡正常。
   - 六面接缝正确。
2. 天气：
   - 龙宫保持原版天气，可与主世界一样下雨/下雪/打雷。
3. 天空光照：
   - `has_skylight: true`，方块受自然天空光。
4. 天灾：
   - 保持原版，不受影响。
